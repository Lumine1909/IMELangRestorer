# IMELangRestorer

Restore the IME language status after you switch back to the edit box, so that it won't change after pressing Shift.

### If you are suffering from on Minecraft 26.2+:
1. Press T to open chat.
2. Switch to English.
3. Close chat, press Shift, open chat, it becomes CJK but not English.

This mod will be helpful for you if you are a Windows user :)
